**Senior Software Engineer · Backend & AI** · Belém, Brazil · Remote

At RecargaPay, a fintech app with millions of users, I built payment services in Java on AWS and, as Tech Lead, led the migration to a new payment gateway provider on a live platform with zero downtime and no lost transactions. #### Featured projects

**[wallet-service](https://github.com/ewerttonbravo/wallet-service)**: open-source digital wallet microservice in Java 25 and Spring Boot.
- Double-entry, append-only ledger with rules enforced by the database: any balance can be audited and rebuilt.
- Mandatory idempotency keys on deposits, withdrawals and transfers.
- Hexagonal architecture verified by ArchUnit; the build fails below 100% line, branch and mutation coverage on the domain (JaCoCo + PIT). Design decisions and trade-offs in [`docs/`](https://github.com/ewerttonbravo/wallet-service/tree/main/docs).

**[papo-reto](https://github.com/ewerttonbravo/papo-reto)** *(in development)*: on-device voice dictation for macOS in Brazilian Portuguese. Runs NVIDIA Parakeet locally, with a benchmark that fails when latency or memory goes over budget.
